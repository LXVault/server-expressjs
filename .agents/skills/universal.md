# Universal Skills

Step-by-step procedures for recurring tasks in this repository, applicable everywhere in
it rather than to one module or surface.

**No skill is defined yet.** This file holds the `universal` scope so a first procedure has
somewhere to land, and so the folder is registered in
[`../index/agents-index.md`](../index/agents-index.md) before it holds anything.

## Adding one

A skill earns a file when a task is done repeatedly, in a fixed order, and getting the
order wrong costs something. A one-off sequence is not a skill.

* Universal to this repository, and short: add it as a section here.
* Universal and substantial: give it its own file, `.agents/skills/{topic}.md`, with
  `name` and `description` frontmatter, and add a row to
  [`../index/agents-index.md`](../index/agents-index.md) in the same commit.
* True for more than this repository: it belongs in the shared set. Propose it under the
  discovery protocol in [`../../AGENTS.md`](../../AGENTS.md) rather than writing it here.

Skills are instruction files, so the discovery protocol applies: propose, do not
self-apply.
